How to use

Getting started

Go to the Monthly budget tab. Under Set up your table, choose how many years to plan for and pick a starting month, then click Generate months table — this creates one row per month.

Filling in your numbers

Type your salary, side income, and expenses for each month. Amber cells are yours to edit; everything else (Total spend, Monthly savings, Savings rate, Emergency fund balance) calculates automatically. A banner will remind you if any month is still empty.

Customizing categories

Under Table columns, remove any expense category you don't need, or add your own (like Subscriptions or Gym) using the "+ Add column" box.

Fixed vs. variable

For anything that stays the same for a while — like rent or a steady salary — switch it to Fixed and set an amount for a period (with a start month, and an end month if it changes later). Add another period to reflect a raise or a rent increase. Leave things that change month to month, like groceries, as Variable.

The emergency fund rule

Set a monthly surplus threshold and a starting balance. Each month, if income minus expenses meets that threshold, that amount is automatically saved to the emergency fund; a smaller surplus goes in fully; a shortfall is automatically covered from the fund if there's enough saved.

Dashboard & forecast

The Dashboard tab summarizes totals, your savings rate, and spending by category. The Forecast tab projects your savings years ahead, scaled automatically to how many months you've filled in — edit the assumptions to see how salary growth, expense growth, or investment returns change the outcome.

Saving your data

Your data saves automatically in this browser. Use Save now any time to confirm it's saved, and Export data (.json) for a backup you can re-import later with Import data.

Working with Excel

Export to Excel downloads a full workbook (Monthly budget, Dashboard, Forecast). Load from Excel reads one back in — handy if you'd rather edit numbers directly in a spreadsheet. On Chrome or Edge on desktop, Connect Excel file… links one specific file so Update linked Excel file and Reload from linked file always work with that same file, in the same folder, every month.

Using OneDrive? If you have the OneDrive desktop app syncing a folder on this computer, just choose a file inside that folder when you click Connect Excel file… — OneDrive picks up the change and uploads it automatically every time you click Update linked Excel file, no extra steps needed.

On iPhone or Android? "Connect Excel file…" only works on Chrome or Edge on desktop. On mobile, use Share / Back Up… instead — it opens your phone's normal share sheet with both a full backup (.json) and an Excel copy of your data attached, so you can save them straight into OneDrive, iCloud Drive, Google Drive, or email them to yourself, in one tap.

Protecting your data if something happens to your device: everything you enter is saved only in this browser, on this device — if your phone is lost, reset, or replaced, that data doesn't exist anywhere else unless you've backed it up. Use Share / Back Up… (or Export data (.json) on desktop) regularly, and keep the .json file somewhere safe like OneDrive or iCloud Drive. If you ever need to restore it — new device, or after a reset — open the app and use Import data with that same file to get everything back exactly as it was, no re-entering required.

Share button not working on mobile? This feature only works when the page is opened via a real https:// link — not when opened directly as a downloaded file or through an app's built-in file viewer (which is common when opening from OneDrive on iPhone). The fix is to host this file somewhere with a real link — for example, free options like Netlify Drop or GitHub Pages — then open that link instead of the local file. Once hosted, saving straight to OneDrive from the share sheet works reliably.

Switching language

Use the English / العربية buttons at the top right to switch anytime — your data stays exactly the same.

البدء

افتح تبويب الميزانية الشهرية. ضمن إعداد الجدول، اختر عدد السنوات التي تخطط لها وحدد الشهر الأول، ثم اضغط إنشاء جدول الأشهر — سيُنشئ هذا صفًا لكل شهر.

إدخال الأرقام

أدخل راتبك، والدخل الإضافي، والمصروفات لكل شهر. الخلايا الكهرمانية هي التي تُدخلها أنت؛ أما البقية (إجمالي الصرف، الادخار الشهري، معدل الادخار، رصيد صندوق الطوارئ) فتُحسب تلقائيًا. ستذكّرك رسالة إن بقي أي شهر فارغًا.

تخصيص الفئات

ضمن أعمدة الجدول، احذف أي فئة مصروفات لا تحتاجها، أو أضف فئتك الخاصة (مثل الاشتراكات أو النادي الرياضي) عبر مربع "+ إضافة عمود".

ثابت أم متغيّر

لأي مبلغ يبقى ثابتًا لفترة — كالإيجار أو راتب مستقر — بدّله إلى ثابت وحدد مبلغًا لفترة معينة (بشهر بداية، وشهر نهاية إن كان سيتغيّر لاحقًا). أضف فترة أخرى لتمثيل زيادة في الراتب أو الإيجار. اترك ما يتغيّر شهريًا، كالبقالة، على وضع متغيّر.

قاعدة صندوق الطوارئ

حدد حد فائض شهري ورصيدًا ابتدائيًا. كل شهر، إذا بلغ الفائض (الدخل ناقص المصروفات) هذا الحد، يُحفظ ذلك المبلغ تلقائيًا في صندوق الطوارئ؛ وإذا كان الفائض أقل، يُحفظ بالكامل؛ وإذا حدث عجز، يُغطّى تلقائيًا من الصندوق إن توفّر فيه ما يكفي.

لوحة المعلومات والتوقعات

يلخّص تبويب لوحة المعلومات الإجماليات، ومعدل ادخارك، والمصروفات حسب الفئة. ويتوقّع تبويب التوقعات ادخارك للسنوات القادمة، بحسب عدد الأشهر التي أدخلتها — عدّل الافتراضات لترى أثر نمو الراتب أو المصروفات أو العائد الاستثماري.

حفظ بياناتك

تُحفظ بياناتك تلقائيًا في هذا المتصفح. استخدم احفظ الآن في أي وقت للتأكد من الحفظ، وتصدير البيانات (.json) لأخذ نسخة احتياطية يمكنك استعادتها لاحقًا عبر استيراد البيانات.

العمل مع إكسل

يقوم تصدير إلى إكسل بتنزيل ملف كامل (الميزانية الشهرية، لوحة المعلومات، التوقعات). ويقرأ تحميل من إكسل ملفًا مثله ليعيد إدخاله — مفيد إن كنت تفضّل تعديل الأرقام مباشرة في جدول بيانات. وعلى متصفح Chrome أو Edge على الحاسوب، يربط ربط ملف إكسل… ملفًا محددًا بحيث يعمل تحديث ملف إكسل المرتبط وإعادة تحميل من الملف المرتبط دائمًا مع الملف نفسه، في المجلد نفسه، شهرًا بعد شهر.

تستخدم OneDrive؟ إذا كان تطبيق OneDrive لسطح المكتب يُزامن مجلدًا على هذا الجهاز، فقط اختر ملفًا داخل ذلك المجلد عند الضغط على ربط ملف إكسل… — سيرصد OneDrive التغيير ويرفعه تلقائيًا في كل مرة تضغط فيها تحديث ملف إكسل المرتبط، دون أي خطوات إضافية.

على آيفون أو أندرويد؟ يعمل زر ربط ملف إكسل… فقط على متصفح Chrome أو Edge على الحاسوب. على الجوال، استخدم زر مشاركة / نسخ احتياطي… بدلاً منه — يفتح قائمة المشاركة المعتادة في هاتفك مع نسخة احتياطية كاملة (.json) ونسخة إكسل من بياناتك مرفقتين معًا، بحيث يمكنك حفظهما مباشرة في OneDrive أو iCloud Drive أو Google Drive، أو إرسالهما لنفسك بالبريد الإلكتروني، بضغطة واحدة.

لحماية بياناتك إن حدث خلل بجهازك: كل ما تُدخله يُحفظ فقط في هذا المتصفح، على هذا الجهاز — إذا فُقد هاتفك أو أُعيد ضبطه أو استُبدل، فلن تكون تلك البيانات موجودة في أي مكان آخر ما لم تكن قد أخذت نسخة احتياطية منها. استخدم مشاركة / نسخ احتياطي… (أو تصدير البيانات (.json) على الحاسوب) بانتظام، واحتفظ بملف الـ .json في مكان آمن مثل OneDrive أو iCloud Drive. وإذا احتجت لاستعادتها لاحقًا — جهاز جديد، أو بعد إعادة ضبط — افتح التطبيق واستخدم استيراد البيانات مع ذلك الملف نفسه لاسترجاع كل شيء كما كان تمامًا، دون الحاجة لإعادة الإدخال.

زر المشاركة لا يعمل على الجوال؟ تعمل هذه الميزة فقط عند فتح الصفحة عبر رابط ويب حقيقي (https://) — وليس عند فتحها كملف تم تنزيله مباشرة أو عبر عارض ملفات داخل تطبيق (وهو أمر شائع عند الفتح من OneDrive على آيفون). الحل هو استضافة هذا الملف في مكان له رابط حقيقي — مثل خيارات مجانية كـ Netlify Drop أو GitHub Pages — ثم فتح ذلك الرابط بدلاً من الملف المحلي. بعد الاستضافة، سيعمل الحفظ مباشرة في OneDrive من قائمة المشاركة بشكل موثوق.
